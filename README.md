# TypeScript Blog Assignment

This assignment contains TypeScript solutions and two easy-to-follow blog posts about important TypeScript concepts. The solution file demonstrates functions, unions, readonly tuples, generics, interfaces, classes, access modifiers, and asynchronous error handling. The first blog explains object-oriented programming access modifiers: `public`, `private`, `protected`, and `readonly`. The second demonstrates how union (`|`) and intersection (`&`) types can be combined in a practical support-ticket example.
